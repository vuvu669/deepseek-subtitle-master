# DeepSeek Subtitle Master

Ứng dụng web dịch phụ đề tự động bằng DeepSeek API (hỗ trợ deepseek-chat V3, deepseek-reasoner R1), chia Part linh hoạt (mặc định 200 dòng/part) và tự động xuất file với hậu tố `_TV-Sub.vi`.

## Hướng dẫn chạy ở Local:
```bash
npm install
npm run dev
```

## Hướng dẫn Deploy Vercel.app:
1. Đẩy toàn bộ thư mục này lên GitHub repository cá nhân.
2. Đăng nhập [Vercel.com](https://vercel.com) với tài khoản GitHub.
3. Nhấn **Add New Project** -> Chọn repository này và nhấn **Deploy**.
